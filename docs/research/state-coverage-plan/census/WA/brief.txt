Civil interval=[2026-06-03, 2026-09-02), IANA accounting zone=America/Los_Angeles. Boundaries are local midnight, start included/end excluded. Backward bands use the same zone/convention. Follow-up uses the per-opportunity/cycle rules below, not an invented common end date.
Scope: state agencies, boards, commissions, colleges/universities with authoritative rule-making publication in Washington State Register (WSR). APA-exempt material is not automatically included: apply the body-based process rules below. Certified PDF is official; HTML is a counterpart, not a second notice. Agency-only announcements never published in WSR are outside the universe; supplied agency material is cross-check evidence only.
- Include CR-102 original comment windows/hearings. Supplemental notices are independently reopened rounds on the existing proceeding. Continuances are updates unless independent reopening is evidenced and flagged for review.
- CR-105 expedited written-objection windows count as written_comment, subtype objection, with objection/receipt conditions retained. No statutory hearing inferred.
- CR-101 counts only when its body states a dated comment deadline or scheduled public meeting on the rule: subtype early_stage. Undated contact invitations are labelled exclusions. Inspect every CR-101; never apply a blanket no-window assumption.
- Inspect every MISC body; include only those opening/changing rule-making comment windows/hearings. Ordinary meeting schedules, opinions/orders, guidance/policy/interpretive statements, court rules and coordinator notices are labelled exclusions.
- Agency/Code Reviser full or partial withdrawals are updates. CR-103P permanent adoptions are closure evidence only, not opportunities/scored updates; preserve rejection/evidence. CR-103E emergency rules/rescissions are excluded.

Carry-in search: [2025-12-03, 2026-06-03), same accounting zone; the first issue gives margin around the 180-day lapse rationale.
