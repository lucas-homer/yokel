# Review scope after explicit delegation

The primary relayed the owner's explicit choice: “Primary releases reviewed jobs within my authorized scope and budgets.” The primary subsequently chose a reviewed local release utility with its signing key in an owner-only directory/file outside the repository (0700/0600). This is acceptable as the intended authority model; this review does not require a second native signer, another Keychain reader, independent approval, or nonexportability.

The file key grants release authority to the primary and other processes able to read it as the same user. Protection from that same user is not claimed. Review should confirm secret-safe errors and output, restrictive creation/access permissions, no key contents in process arguments or repository artifacts, and deliberate refusal to overwrite existing signing custody or immutable releases. The bootstrap service token remains protected by the existing native Keychain boundary. File-based signing custody must not create a token export path or relax existing Keychain trust.

The stable runner must retain the existing fixed service/account, exact authenticated identity, pinned op binary, no runtime UI/fallback, token removal at the provider-payload boundary, sanitized environment and streams, core suppression, and bounded process-group cleanup. Signed external jobs must bind exact canonical bytes across stages, enforce existing provider-reference subsets and fixed isolated Python/adapter argument grammar, validate dependency pins before credential-bearing dispatch, and consume job identity before execution. Scope/review hashes establish signed provenance, not independent validation of the review's conclusions. Monetary metadata must preserve integer nanodollars; actual spend and call limits remain obligations of the reviewed adapter and ledger.

Production implementation review and primary-owned migration remain separate from the accepted synthetic prototype. Real no-prompt continuity requires post-migration evidence; no synthetic result establishes it.
