# **DEPARTMENT OF**
# **LABOR AND INDUSTRIES**

## **WSR 26-16-026A**
## **WITHDRAWAL OF PROPOSED RULES**

[Filed July 28, 2026, 11:43 a.m.]

The department of labor and industries (L&I) is withdrawing the CR-102 proposed rule making filed on February 3, 2026, and published under WSR 26-04-112. The comment period for the proposed rule making was from February 4, 2026, to March 10, 2026.

Due to technology resource constraints and uncertainty about our ability to prioritize this work, L&I is not able to make system changes to support the requirements of this rule change. For this reason, we have decided to withdraw the rule making. L&I will revisit implementation and system options, consult with stakeholders, and file a new CR-101 preproposal if/when appropriate.

If you have any questions, contact Caitlin Gates, rules coordinator, at Caitlin.Gates@Lni.wa.gov or 360-902-6744.

Caitlin Gates
Rules Coordinator
