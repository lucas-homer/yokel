Search and access more data

Parse one supported document into markdown, HTML, links, summary, targeted answers, or JSON matching a schema. Supported inputs include common HTML, PDF, Word, RTF, OpenDocument, and spreadsheet files; PDF parsing can be bounded with `pdfOptions.maxPages`.

Local MCP reads `filePath` from the server filesystem. Hosted MCP uses two calls: first provide `filePath` to receive upload instructions, upload locally, then call again with the returned `uploadRef`; do not send both fields together. Remote web URLs belong in `firecrawl_scrape`.

Set `redactPII` to request redaction of personally identifiable information in the returned content. `zeroDataRetention` requires an eligible authenticated account; omit it for anonymous keyless use. Returns upload instructions for hosted phase one or parsed document content for the final call. Authenticated final responses can include a `data.metadata.scrapeId` for optional parse feedback. This tool is part of plugin `Firecrawl`.

exec tool declaration:
```ts
declare const tools: { mcp__codex_apps__firecrawl_firecrawl_parse(args: {
  // Phase 1 MIME type override. If omitted, the server infers it from the file extension without reading the file.
  contentType?: string;
  // Optional phase 1 size declaration. Hosted MCP does not stat the file; provide this only if the caller already knows it.
  declaredSizeBytes?: number;
  excludeTags?: Array<string>;
  // Phase 1 only: path to the local file on the caller/harness machine. Hosted MCP will not read or stat this path; it is used only to produce upload instructions.
  filePath?: string;
  formats?: Array<"markdown" | "html" | "rawHtml" | "links" | "summary" | "json" | "query">;
  includeTags?: Array<string>;
  jsonOptions?: { prompt?: string; schema?: {}; };
  // Ignored: parse never reuses or stores indexed content.
  maxAge?: number;
  onlyMainContent?: boolean;
  parsers?: Array<"pdf">;
  pdfOptions?: { maxPages?: number; };
  proxy?: "basic" | "auto";
  queryOptions?: { mode?: "directQuote" | "freeform"; prompt: string; };
  redactPII?: boolean;
  removeBase64Images?: boolean;
  skipTlsVerification?: boolean;
  storeInCache?: boolean;
  // Phase 2 only: short-lived upload reference returned by phase 1 after the local PUT upload completes.
  uploadRef?: string;
  zeroDataRetention?: boolean;
}): Promise<CallToolResult<{
  // Optional response guidance from the Firecrawl API.
  agent_hints?: Array<string>;
  // Parsed document content; can include `data.metadata.scrapeId` for parse feedback.
  data?: unknown;
  // Error message or error object when the call did not succeed.
  error?: unknown;
  // Guidance for the next call.
  message?: string | null;
  // Which phase of the hosted flow produced this response.
  mode?: string | null;
  // Hosted phase one: the second `firecrawl_parse` call to make once the upload succeeds, as `{name, arguments}`.
  nextToolCall?: unknown;
  // Hosted phase one: constraints on completing the upload flow.
  notes?: Array<string> | null;
  // Response body when it was not JSON.
  raw?: string | null;
  // Whether the API call succeeded.
  success?: boolean | null;
  // Hosted phase one: how to upload the local file.
  upload?: {
  // Local command that performs the upload. It carries no Firecrawl API key.
  command?: string | null;
  // When the upload URL expires.
  expiresAt?: string | null;
  // Form fields the upload request must send, for a POST upload.
  fields?: unknown;
  // Headers the upload request must send.
  headers?: unknown;
  // Largest file the upload URL accepts.
  maxSizeBytes?: number | null;
  // HTTP method for the upload.
  method?: string | null;
  // Reference to pass back on the second call.
  uploadRef?: string | null;
  // URL to upload the local file to.
  uploadUrl?: string | null;
};
  // Non-fatal warning about the result.
  warning?: string | null;
}>>; };
```
