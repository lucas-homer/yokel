# Evaluation interchange v1

Files are JSON Lines, except `progress.json`. Paths are relative to the benchmark artifact root. Keys are stable. The primary may read these incrementally; aggregate only `evaluation_status == "complete"`. A pending row has null outcome/status and is never an observed failure.

- `field-scores.jsonl`: exactly 696 scheduled rows; key `(fixture_id, arm, field_id)`. Fields: `evaluation_status`, `input_sha256`, `reference_version_hash`, `semantic_group_id`, `critical`, `answerability`, `operation_status`, `outcome`, `reason_code`, `scope_coverage` (`complete`, `partial`, `none`, `not_assessable`), `source_locator`, `output_artifact`, `output_artifact_hash`, `output_locator`, `exact_output_quote`, `omission_scope`, `decisive_relation_preserved`, `field_gate_pass`, `reviewer_id`, `adjudication_note`. Quotes are exact substrings of the named output; locator has 1-based lines and Python Unicode character offsets `[start,end)`. Failed/empty operations carry null quote with an explicit omission/operation scope. Uncertain references are `not_assessable`, never successful guesses.
- `document-scores.jsonl`: exactly 80 scheduled rows; key `(fixture_id, arm)`. Fields: `evaluation_status`, `input_sha256`, `reference_version_hash`, `operation_status`, `gate_outcome`, `reference_gate_eligible`, `scope_coverage`, `notice_scope`, `output_artifact`, `output_artifact_hash`, `critical_field_counts`, `critical_group_counts`, `extra_assertion_audit_complete`, `critical_extra_assertion_ids`, `failure_categories`, `reviewer_note`. Gate outcomes follow the frozen contract. `gate_outcome=insufficient_reference` takes precedence for A07; retain operation status and content counts separately.
- `extra-assertions.jsonl`: one row per discovered erroneous/contradictory assertion, deduplicated across affected fields; keys include `assertion_id`, `fixture_id`, `arm`, `assertion_text`, `output_artifact`, `output_artifact_hash`, `output_locator`, `source_scope`, `error_type`, `critical`, `reason`, `affected_field_ids`. An empty ledger plus a completed document audit means no such assertion was found, not proof of exhaustive extraction precision.
- `operation-records.jsonl`: one per scheduled document-arm; native or provider operation classification and retained evidence. Latency/usage remain null if unavailable; do not infer cost.
- `progress.json`: completion counts and notes. Initial rows are scaffolding until explicitly completed.

Arms: `native`, `firecrawl_local_parse`, `llama_agentic`, `llama_agentic_plus`.

Content outcomes: `supported`, `partial_ambiguous`, `missing`, `incorrect`, `safe_abstention`, `not_assessable`.
Operation statuses: frozen contract's values; null while pending. A native extraction with no embedded text is `completed_empty`, with reason `native_no_embedded_text`; distinguish it from service errors.

Metrics: use frozen `review/scoring-contract.json`. Positive critical evidence yield includes all scheduled determinate positive/explicit-negative references. Conditional content scores require `completed_nonempty`. Group facets by `semantic_group_id`; never count groups as statistically independent. A document passes only if all critical field gates pass, the frozen reference is eligible, the output is completed/nonempty, and the extra-assertion audit is complete with no critical errors. Output text preservation is being reviewed; no downstream field extractor is run. Review is agent-authored and not blinded or human gold.

Completed-result additions: `absence_evidence_checked` explicitly records full-scope negative review. `aggregate.json` contains paired tables and labeled metric denominators; `strata.json` contains notice/group denominators for diagnostic slices. Firecrawl `wrapper_wall_ms` is recorded parse-wrapper elapsed time and can include local pacing/queue waits; it excludes separate upload/setup and must not be described as provider service speed. Original rate rejection evidence is retained in each recovered operation record. `score-correction-history.json` preserves the removed A03 false extra-assertion finding.
