# Round6 service-account adapter — ready for primary review

This is credential wiring around the **unchanged frozen runtime**, not a runtime/protocol/model change. Own edits are confined to this directory. No native runner build, install, enrollment, Keychain/op call, credential retrieval or provider call was performed by this child. Primary owns policy review/build/enrollment and actual live execution.

`adapter.py` has exactly two fixed modes: `--check` and `--live-initial`. No caller-supplied paths, references, budget, model, provider, completion caps or argv override. Launch only with the resolved bundled Python3.12 executable and `-I -S -B`: isolated Python, no site startup/.pth hooks, no bytecode writes. Fixed reviewed runtime and package roots are then added explicitly. The adapter calls `runtime.run` directly and never invokes the frozen Private-reference shell wrapper. Its only credential access is the two injected environment variables within the live entry after verification; unresolved op references, empty keys or an inherited service-account token are rejected. No credentials are accessed in check mode.

Before loading runtime, the adapter checks its nonsecret dependency manifest; hardcoded receipt hashes for Freeze A/S/B; every freeze entry's exact bytes/hash and confined path; original implementation/source manifest hashes; and exact original six-field live authorization. Reference entries are verified as opaque bytes only, without interpreting truth. Runtime subsequently re-verifies its own pins/source/auth under the original code. Fixed source root is `round6/sources`, original manifest `sources/source-inputs.READY.json`, output `execution/run`, original authorization `execution/live-authorization.json`, budget $2, max-new24 and original models/prompts/caps. Four real notices/three states/fourteen pages remain a **cohort shortfall**, not an eight-notice experiment.

Initial live entry refuses an existing `execution/run` or prior `live-intent.json`. It performs the unchanged runtime's dry validation before accessing injected keys. A write-once fsynced `live-intent.json` records only reviewed hashes, budget, cap, timestamp, fixed output path and no-retry status. Runtime stdout/stderr is discarded in-process; terminal errors are fixed generic text without exception strings. `live-result.json` retains only an enumerated state, budget/cap and fixed output path; `live-stop.json` retains a fixed stopped/uncertain marker. Runtime writes its existing approved durable artifacts and retains its fail-closed no-POST-retry behavior. Interrupted/paused/stopped executions are not automatically re-entered: this initial-only job refuses subsequent execution, and primary must reconcile retained artifacts and review any future resume wiring. A missing final adapter receipt does not prove zero calls. The adapter records no provider cost or semantic result claims; primary audits the runtime ledger.

`native-job.json` is one job object suitable for inserting unchanged beneath a primary-chosen policy `jobs` name: fixed argv, `files`, timeout1800. It pins2465 files: executable, adapter, dependency manifest, original authorization, all Freeze A/S/B entries, full bundled stdlib including existing bytecode/extension imports, Python dylibs, full pypdf/cryptography/PIL/cffi package roots/supporting extension files and pypdf metadata. `dependencies.json` pins2464 files excluding itself; the native job pins that manifest separately. `prepare_manifest.py` is a nonsecret offline generator, not a live job. No package install or build occurred. No source/reference/frozen file was edited. Native policy must be rebuilt/reviewed by primary; do not add this job to the already-enrolled binary without that process.

System libraries, network resolution, TLS system trust, interpreter/native loader behavior and hostile same-user/filesystem races remain outside these content hashes. This is the trusted-job boundary documented by the native runner, not privilege separation. Pinning includes existing bytecode because -B prevents writes but does not prevent reads. Explicit site path can expose optional packages; paid imports actually used by unchanged runtime are pypdf and its crypto/image support, pinned in full. Installed system dependencies and OS libraries are not vendored or independently verified here. Hashing every frozen original/excluded source increases startup work but introduces no source selection or semantic inspection. Timeout1800 is an execution budget, not a completion guarantee; a timeout can leave a durable uncertain intent requiring primary reconciliation.
