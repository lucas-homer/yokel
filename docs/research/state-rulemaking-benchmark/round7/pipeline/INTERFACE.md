# R7 offline research interface

Version: round7-participation-record-1.0.0. All outputs action_ready=false and production_eligible=false. See ../SPEC.md for approved policy. No display feature is implemented; arbitrary display fields reject.

Public APIs retain R6 signatures: make_source, inventory_request, assemble, verification_payload, verification_request, jev_question_specs, validate_verdict. Schemas in this directory are authoritative; R6 versions reject. Source-first inventory requests carry only source, prompts and response schema. Assembly performs strict evidence/shape/reference checks, never semantic completeness acceptance. Invalid whole records remain null. Full native text stays unchanged.

Routes use nonempty components [{id,kind,literal,evidence}], nullable description, alternative_group_id, and existing role/channel/event_ids/association/evidence. Every literal must be contiguous in its own exact evidence; every component is globally identified and assessed. Description is an independently audited claim, never endpoint. Groups [{id,purpose,route_ids,event_ids,requirement_ids,association,evidence}] have reciprocal membership, >=2 distinct routes and exact equal event-id sets between all member routes and the group. Purpose/role mapping: submission/submission; hearing_registration/hearing_registration; hearing_access/other; hearing_help and copies_questions_accessibility/information_contact; other/other. Linked qualifications must target only group member routes. Route-specific requirements remain independent facts. Exact evidence proves neither component ownership nor interchangeability; semantic audits judge those claims. Uncertain groups emit association_unresolved.

all_items includes components and groups, counted against the existing aggregate 200 ID cap and exact stronger-verdict assessment coverage. Evidence resolution preserves Unicode end-exclusive offsets, repeated-quote disambiguation, and context/occurrence consistency. Missing/duplicate verdict assessments or altered assembled envelope fail validation. No source/fact clipping or automatic repairs.

Complete named-month/ISO dates may have English full or three-letter weekday prefix, optional period/comma and whitespace. A printed weekday must agree with the Gregorian printed date; inconsistent weekday produces a distinct error. Missing years, invalid dates, numeric ambiguity and clock/prose suffixes never normalize. Other timing kinds retain raw and null value; relative/conditional bindings unchanged.

Canonical paired payload carries full source once plus all record facts, component/group evidence, review reasons and hashes. Both arms receive the exact same payload. Jev remains five non-generative Choice probes; stronger emits the closed verdict schema including component/alternative_group missing-item kinds. Independent audited source mapping, not structural validation/model claims, establishes semantic correctness or omissions.
