# Source-first comparison: useful detection gains, incomplete coverage assurance

The two-stage run correctly detected both previously missed source-to-record losses in the reused Wisconsin notice: repeal/recreation details and the full Zoom/phone alternatives relationship. Independent semantic review confirmed both detections. This supports further testing of source-first verification; it does not establish general accuracy or production readiness.

Stage A saw only the source and generated an evidence-backed inventory. Stage B received the frozen inventory, full source, and operative normalized record, then matched each inventory item to record fields. Both calls completed without retries, repair, clipping, or a new macOS/1Password prompt in this logged-in session.

A produced 46 units and B mapped all 46. B's 27 matched, 6 mismatched, 8 missing, and 5 unknown judgments are raw model claims, not an accuracy score. All 31 original source units had some local representation, but that is not strict complete recovery. Compound assertions, original glyph ambiguity, and accessibility reference uncertainty remain. ## Recommended next experiment

Specify participation scope before scoring missing content. Retain source-supported background facts and provenance, but distinguish them from required participation fields. Split endpoints, their roles, and relationships into independently testable units; expressly preserve query-only versus submission roles. Decide prospectively when separate viewing permissions require an explicit alternatives group.

Then freeze those rules and evaluate fresh, unseen notices with independently adjudicated source obligations. Compare direct verification and source-first verification on the same cases, tracking missed obligations, false alarms, unresolved cases, and cost per correctly verified record. Do not enlarge models or budgets merely to compensate for undefined scope. No further paid calls were made in this round.
