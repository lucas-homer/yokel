# R17 scoring fixtures (design r2)

All sources, references and outputs here are **fictional**, except F21. F21 pins the frozen R15 fictional control (`round15-condition-preservation/protocol-revised/fixtures/{source.txt,expanded.json}`) by SHA-256 to prove that the scorer reads a real r16 expanded record. Expected judgments were written by hand from ADJUDICATION-SPEC.md, not generated by the scorer.

| File | Role |
|---|---|
| `cases.src.json` | Authored cases. Quotes are `[text, occurrence]`. |
| `cases.json` | Built form, with every quote resolved to explicit `start`/`end`/`occurrence`. `check.py` refuses to run if it is stale. |
| `r17score.py` | The mechanical scorer (ADJUDICATION-SPEC Part B). It also provides `validate-reference` for the E4 quote check, and `score`. |
| `check.py` | The checker: rebuilds, validates and scores every case, compares against expectations, and checks adjudicator fixture files (`--adjudications DIR`). |

```sh
python3 -I -S -B check.py                       # exit 0 = every expectation holds
python3 -I -S -B check.py --write               # rebuild cases.json after editing cases.src.json
python3 -I -S -B check.py --adjudications DIR   # DIR/<A1|A2>/<case_id>.json, ADJUDICATION-SPEC Part A format
python3 -I -S -B r17score.py validate-reference REF.json parsed-body.txt
python3 -I -S -B r17score.py score REF.json parsed-body.txt OUTPUT.json ADJ.json OPQ|FULL
```
