Keep semantic assertions atomic even when they cite the same line. ## Span granularity and reconstruction

Use a deterministic table keyed by source hash and ordinal (for example, `l001`). Record exact start/end boundaries computed by the host. Define the offset domain once: Unicode codepoints with an exclusive end is reasonable for Python; do not accept byte or UTF-16 offsets as equivalent. A covering partition must retain line delimiters, blank lines and the missing final delimiter exactly. Reassembling all partition slices in source order must reproduce the original UTF-8 bytes and SHA-256. Store or retain the raw bytes separately; decoded text equality alone cannot establish byte identity.

Whole lines minimize segmentation assumptions. This notice's contact, deadline and proposed-rule lines contain multiple independent assertions: one span may support several units. Spans are evidence containers, not unit boundaries. Remove the old 320-character quote restriction from the compact selector path: a source line can exceed it, and clipping would discard evidence.

Clause IDs are an optional later refinement when measured ambiguity or input size warrants them. A deterministic splitter must retain punctuation, markup and whitespace and keep parent lines available. Splitting on every comma/semicolon or apparent period is unsafe around addresses, abbreviations, numbered provisions and deleted text. Nested clause slices must not be concatenated alongside parent slices during source reconstruction. Fix segmentation/version before release; do not let the model propose offsets or silently mint missing spans. Allow several span IDs per unit when context and operative text are separated.

## Compact semantics

Prefer short named keys over positional tuples unless the actual request serializer demonstrates reliable tuple support. Do not assume a JSON-schema dialect supports heterogeneous tuple arrays. Keep the schema small and closed; decode into a documented expanded object. Use one envelope version/source binding and derive resolved evidence quotes mechanically from IDs. A host-derived hash in the expanded result binds local context; if the model omits the hash, retain the exact frozen request/response association so the host is not merely stamping arbitrary output as authenticated.

Required per-unit information is identity, kind, assertion, actor, purpose/role, modality, conditions/applicability, evidence IDs, and relationship members when applicable. Actor and purpose may be explicit compact fields or unambiguously encoded by a documented assertion contract; shortening must not erase them. A transport codec can prove equality of defined objects, but cannot prove that prose retained every semantic distinction. Prefer explicit role/actor fields if subsequent processing needs to inspect them.

Safe defaults need exact meanings: omitted dependencies means an empty list; omitted uncertainty means no uncertainty reported by the model and an empty reason, not independently verified certainty. Explicit ambiguity/unresolved-reference states require a nonempty reason and evidence. Conditions, actor, purpose and modality must not default to universal applicability, generic contact, informational or certainty. Absent unknown information remains explicit where it affects interpretation. If the output schema requires all keys, an empty list/null sentinel may replace omission with the same documented semantics. Never silently drop explicit values during expansion or accept conflicting default and override encodings.

Preserve the distinction between endpoint literals and each purpose served by them. A shared address or phone can support different role units; only the evidence storage is shared. Keep descriptive/background assertions, amendment action, drafting/implementation/enforcement responsibilities, qualifications, relative deadline anchors, unresolved cross-references, and deleted/proposed/current text distinctions. Dependency edges and relationship-member edges have different meanings; freeze their contracts and do not impose an acyclic rule on every relationship merely because dependency edges are acyclic.

## Acceptance tests

1. Partition roundtrip: preserve LF/CRLF, blank lines, trailing whitespace, no final newline, combining characters, astral characters and repeated identical lines. Compare reconstructed raw bytes and hash. Require a stable identical span table on repeated builds.
2. Selector integrity: reject unknown IDs, wrong source hash/version, empty/out-of-range spans and stale tables. Repeated text at different locations gets different IDs and resolves to its own occurrence. Reject booleans where integer offsets are required.
3. Decode roundtrip: compact -> expanded -> compact has canonical equality; explicit expanded defaults reconstruct exactly. Preserve unit order, Unicode and evidence order according to the frozen contract. Include nonempty uncertainty, multiple evidence spans and relationships in the fixture.
4. Strict syntax: reject duplicate JSON keys, extra keys, duplicate unit IDs, unknown enum values, wrong tuple arity if tuples are used, trailing prose, truncation and missing terminal closure. Reject non-normal provider finish status even if visible text parses.
5. Graph validation: reject unresolved unit references, prohibited self-dependencies and dependency cycles; require all relationship members. Deduplicating evidence must not deduplicate distinct role assertions.
6. Defaults: test omitted/explicit empty dependencies and uncertainty separately. Reject nonempty reason with certainty, ambiguity without reason, and conflicting encodings. Test unknown actor/force/reference target without silently inserting a known value.
7. Atomicity counterexample: one line contains two actors with different deadlines or conditions. Require separate assertions retaining each actor/role/force/condition and anchor; both may cite one line. A syntactic validator alone cannot decide this test, so retain a human/independent semantic rubric.
8. Shared contacts: a literal used for submissions and accommodations resolves to two purpose units with distinct timing and dependencies. Co-listing phone/email/fax alone must not create an unsupported substitution or submission role.
9. Amendment/qualification fixture: preserve deleted `((...))` text as marked source evidence while describing proposed operative text correctly; retain `unless otherwise specified`, service requirements and relative date anchors. A source-span match is necessary but does not establish entailment.
10. Background/uncertainty retention: a deliberately nonparticipation fact and an unresolved external reference survive compact/expanded roundtrip. Complete span citation coverage cannot prove assertion coverage: include a fixture where every line is cited but a second obligation in one line is omitted.
11. Capacity failure: any safety limit on units, spans, reasons or relationships produces an explicit rejected/incomplete result, never silent clipping. A terminal marker means closed serialization only. Do not treat reaching a unit limit as exhaustive discovery.
12. Full-output sizing: serialize complete synthetic inventories at expected and stressed granularity, including long conditions, uncertainty and relationships, with all envelope/schema costs and exact request bytes. Record fixture provenance and do not use repaired R12 prefixes as valid inventories.

## Offline sizing and evaluation decision

Measure both full canonical UTF-8 request size plus the 1,024-byte guard (<=40,000 for this proposed pilot) and full output capacity. Count exact tokens with an already available, disclosed tokenizer matching the intended model if possible. Without one, label byte/character ratios as estimators and show sensitivity; a four-characters-per-token estimate is not a reliable upper bound. Report residual capacity under the 8,192-token completion limit, including reasoning allowance, envelope and adverse fixtures. A prudent proposed acceptance target is <=70% of that cap for the representative complete fixture and <=85% for stressed fixtures, leaving explicit headroom; these thresholds are design choices, not proven sufficiency or a unit ceiling. The primary should freeze its chosen target before execution.

Offline codec tests can establish exact source reconstruction and preservation of defined fields. They cannot establish model discovery, entailment or completeness. Audit semantic omissions independently at the assertion level: actor, purpose, force, condition, dependency, amendment status, background and uncertainty. On fresh cases, freeze references before output and keep outcome-exposed engineering cases separate. Even a fully closed pilot with valid selectors establishes only serialization feasibility until those semantic checks pass. Later scope/mapping stages need their own capacity and fidelity evaluation; this source-only diagnostic cannot support an end-to-end or direct-versus-staged performance claim.
