## Exact source and host evidence

span_table(source) deterministically uses Python str.splitlines(keepends=True). Every Unicode codepoint, line separator, blank line and final line without terminator belongs to exactly one ordinal span s1,s2,... . IDs are stable for identical source/version; they are not cross-document identities. Offset domain is Unicode codepoints, end exclusive. The model sees the full immutable source plus every host row [ID,start,end,exact_line_text], and selects IDs from the adjacent text without manual offset reasoning; it never invents offsets, source quotations or new IDs. Reassembling slices preserves source text, exact UTF-8 bytes and SHA256. Original raw HTML/reference artifacts remain primary-owned provenance; this table does not repair extraction or missing links.

Whole-line spans may exceed old quote limits and contain several claims. Several distinct units may cite the same span, or one unit several spans. Broad span-level provenance is not assertion entailment, atomization, discovery or semantic completeness. Neither all IDs cited nor a terminal marker certifies every assertion in a cited line. Unknown references/glyphs remain unknown; no background or unresolved function may be dropped to reduce output. Empty/unknown span IDs, stale source/table hash, changed offsets/order or versions reject.

## Minimal generated object

Envelope keys are exactly v,h,t,u,z. v=r13.1, h is exact source UTF-8 SHA256, t is canonical span table SHA256, u is ordered inventory units and z=END. Hashes must be echoed by the model under source-instantiated schema; host never patches missing/stale hashes into arbitrary output. Each unit has ten required short keys:

| Key | Meaning |
|---|---|
| i | Unique integer unit ID1..160; gaps allowed, order preserved |
| k | Kind code0identity,1rule_transition,2phase,3timing,4endpoint,5endpoint_role,6instruction,7relationship,8background |
| s | Atomic assertion with supported actor, action/object and single purpose explicitly preserved |
| m | Force code0informational,1mandatory,2advisory,3optional,4prohibited,5unknown,6not_applicable |
| c | Conditions/applicability/qualifications, including actor/context needed for meaning |
| d | Prerequisite unit IDs; complete, unique, acyclic |
| b | Relationship-member IDs, separate from prerequisites; all present, unique, no self-membership; no acyclicity rule on member edges |
| e | One to six exact host span IDs, unique within unit; reused across units allowed |
| q | Uncertainty code0none,1source_ambiguous,2reference_unresolved,3function_unresolved |
| r | Exact uncertainty reason; empty iff q0 |

All keys are required; no omitted-key default/coercion. Explicit c="" means the model reports no stated condition for that assertion, not verified universal eligibility or absence of relevant context. Explicit d=[] means no prerequisite reported, not resolved external references; b=[] is required on nonrelationships. q0/r="" means no uncertainty reported, not independent certainty. Unknown applicability, actor or purpose is stated in s/c and marked uncertain; unknown force m5 requires q!=0. Host cannot prove these language judgments from strings. Modality never silently defaults; s is never replaced by evidence. Exactly160 units hits the safety limit and is rejected for capacity review; fewer units are not evidence of exhaustive discovery. String/list bounds must not induce semantic clipping. Raw incomplete output is retained as failure, not repaired.

Endpoint literal/components and each purpose served are separate units; role k5 first d target must be endpoint k4. Additional prerequisites are allowed. Sharing a phone/address cannot merge submission/questions/accommodations roles or invent functional substitution. k7 has at least two b members and preserves purpose, full semantics and qualifications in s/c; d retains true prerequisites separately. Functional equivalence requires source support, not co-listing. Independent viewing permissions need no invented group. Distinct current/proposed/deleted text, relative timing anchors, exception conditions and background survive.
