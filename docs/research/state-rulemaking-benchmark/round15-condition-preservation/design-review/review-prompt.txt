# R15 Condition-Graph Contract (Proposal)

## 0. Decision summary

R15 replaces unit `c` with three things:

1. A **global DAG of condition nodes** `g`. Leaves are bound to source text through **anchor-pair fragments** that the host resolves to exact text. Typed operators combine the leaves.
2. **Explicit typed links** `l` from units to node roots.
3. A per-unit **applicability state** `p` and a **deadline-dimension slot** `y`.

R14 stays frozen. Nothing is evaluated or resolved. Validation proves only structure and exact evidence match.

## 1. Alternatives considered

| Option | Verdict |
|---|---|
| A. Raise `c` to 2000 chars | Rejected. Logic stays in prose, scope leakage can't be represented, long text gets rewritten, and nesting is ambiguous. |
| B. `c: string[]` (one string per qualification) | Rejected. It has the same prose problems with no binding to structure. |
| C. Leaves cite whole line spans (reuse `e`) | Rejected. A line can't isolate one clause, repeated phrases on a line are indistinguishable, and a 600-char qualification shares its line with other clauses. |
| D. Host word-token table plus ID ranges | Viable but rejected. It inflates input roughly 3–5×, and reading IDs beside many tokens is error-prone. |
| **E. Anchor-pair fragments: short exact head/tail copies plus occurrence indexes; the host extracts the full text** | **Chosen.** It is short to emit, preserves unbounded exact text, cross-line and discontinuous evidence, and disambiguates repeats. It fails closed on any mismatch. |
| F. Normalized predicate logic (typed actors, time variables, sufficiency) | Rejected as expansive legal semantics. |

On graph placement, per-unit inline trees duplicate shared clauses. A global DAG with explicit links makes sharing visible, and the absence of a link is visible too.

## 2. Types (closed objects; every key required; no defaults)

```ts
type SpanId = /* enum bound from span table, e.g. "s1".."sN" */ string;
type UnitId = number;            // integer 1..160, unique (R14 space)
type NodeId = string;            // /^c[1-9][0-9]{0,2}$/, numeric value 1..400, unique
type Q = 0|1|2|3;                // 0 none,1 source_ambiguous,2 reference_unresolved,3 function_unresolved
type Anchor = string;            // 1..48 codepoints, exact source copy

// Fragment tuple: [startSpan, head, headOcc, endSpan, tail, tailOcc]
type Frag = [SpanId, Anchor, number /*>=1*/, SpanId, Anchor, number /*>=1*/];

interface Envelope {
  v: "r15.0"; h: string /*source hash enum*/; t: string /*table hash enum*/;
  u: Unit[];   // 1..160; length 160 => reject capacity_review
  g: Node[];   // 0..400; length 400 => reject capacity_review
  l: Link[];   // 0..400; length 400 => reject capacity_review
  z: "END";
}

interface Unit {               // R14 fields kept except c; p and y added
  i: UnitId; k: 0|1|2|3|4|5|6|7|8; s: string /*1..280*/;
  m: 0|1|2|3|4|5|6;
  p: 0|1|2;                    // applicability: 0 none_reported, 1 reported_nonexhaustive, 2 unknown
  y: Deadline | null;
  d: UnitId[] /*0..16*/; b: UnitId[] /*0..16*/; e: SpanId[] /*1..6*/;
  q: Q; r: string /*0..180*/;
}

interface Deadline { c: Dim /*cutoff clock*/; z: Dim /*timezone*/; b: Dim /*receipt vs dispatch basis*/ }
interface Dim {
  s: "stated"|"absent"|"ambiguous"|"na";
  x: Frag[];                   // absent: exactly 0; others: 1..4
  r: string;                   // 0..180; nonempty required for ambiguous and na
}

interface Node {
  i: NodeId;
  o: "L"|"R"|"AND"|"OR"|"NOT"|"EXC"|"ALT";
  a: NodeId[];                 // ordered children (arity in §3)
  x: Frag[];                   // L/R: 1..8 (content evidence); operators: 0..4 (connective evidence)
  g: string;                   // 0..120 model gloss, NON-authoritative
  q: Q; r: string;             // 0..180
}

interface Link {
  u: UnitId;
  w: "if"|"onlyif"|"unless"|"regardless"|"obj"|"acts"|"qual";
  n: NodeId;                   // root of the linked subgraph
  x: Frag[];                   // 0..2 connective evidence (e.g. "only", "unless")
  q: Q; r: string;             // 0..180
}
```

### Enum meanings

**Node operators.** None of them is evaluated.

- `L` is a source-stated condition whose content is in the supplied source.
- `R` is a cross-reference or antecedent whose governing content is *not* in the source. The host never resolves it.
- `AND` / `OR` record source conjunction and disjunction. OR inclusivity is not asserted. If exclusivity is unclear, use node `q1`.
- `NOT` records explicit source negation.
- `EXC` takes ordered `[base, carveout]`, where the carve-out excepts the base condition.
- `ALT` records competing readings of the same text, exactly one intended and unresolved.

**Link roles.**

- `if`: the assertion is stated to hold under the root. Sufficiency or necessity is not asserted.
- `onlyif`: the source restricts the assertion to cases where the root holds.
- `unless`: the assertion is stated not to hold, or to be displaced, where the root holds. This is a carve-out against the unit itself, with no fabricated base.
- `regardless`: the source explicitly states the assertion holds irrespective of the root.
- `obj`: the root structures the *object or performance* of the directive (what is supplied), not when it applies.
- `acts`: the unit operates on the root (waiver, modification, override). No effect is computed.
- `qual`: a source-bound qualification whose applicability-logic role is not asserted. This is the safe harbor when a phrase's role is uncertain.

### Meanings of empty values

- `p=0` means the model reports no applicability condition. It does **not** mean the assertion is unconditional.
- `d=[]` means no link is reported.
- `y=null` on a k3 unit means the model claims it is not a deadline assertion. On other kinds, `y=null` is required.
- `x=[]` on an operator or link means no connective evidence is cited.
- `g=""` means no gloss.

## 3. Invariants (host-checked)

**Unit (R14 carried over).** IDs are unique. `d` is acyclic, and every ID in `d` and `b` exists. k7 has `b` with at least 2 members; all other kinds have `b=[]`. A role unit (k5) has its first `d` entry pointing to a k4 unit. `e` has no duplicates. `q=0` iff `r=""`. `m=5` requires `q≠0`.

**Applicability (`p`).** Count the unit's links with `w ∈ {if, onlyif, unless}`; call this A.

- `p=0` requires A=0.
- `p=1` requires A≥1.
- `p=2` requires unit `q≠0`, and A may be any value (partial conditions are allowed).
- Each unit has at most one link per role in `{if, onlyif, unless, obj}`, so multiple conditions must be combined explicitly with AND or OR.
- `regardless`, `acts` and `qual` links may repeat and may appear with any `p`.
- The triple `(u, w, n)` is unique.

**Modality independence.** The host never derives or constrains `m` from node or link `q`. An unresolved R leaf on an `m1` unit is valid.

**Deadline (`y`).** `y≠null` only when `k=3`.

- `na` is allowed only on `y.b`, with evidence of the source-established function in `x` and the basis in `r`.
- If any dimension is `absent` or `ambiguous`, unit `q≠0`.
- A `stated` value is the fragment text. It is not normalized, converted to an offset, or resolved.

**Node arity and kind.**

| Operator | Children `a` | Other rules |
|---|---|---|
| `L` | 0 | none |
| `R` | 0 | requires `q=2` |
| `NOT` | 1 | none |
| `EXC` | 2, ordered | none |
| `AND`, `OR` | 2..8, distinct | none |
| `ALT` | 2..8, distinct | requires `q=1` |

**Node graph.**

- Every child and every link `n` exists. Every link `u` exists.
- There are no self-children and no cycles over `a`.
- Sharing is allowed: a node can have multiple parents and multiple links.
- **No orphans:** every node is reachable from some link root.
- Depth is at most 12, with a root at depth 1.

**No inheritance.** Conditions never propagate through `d`, `b`, shared evidence, or shared parents. A unit is linked only to what its own links name.

**Fragment resolution (deterministic).** Let row A = span `a` and row Z = span `z`, with ordinal(Z) ≥ ordinal(A).

1. Find all indices j where `A.text.startswith(h, j)`, ascending and including overlapping matches. Take the `o`-th; if it doesn't exist, fail. Set `start = A.start + j`.
2. Find candidate indices k where `Z.text.startswith(t, k)`, keeping only those with `Z.start+k ≥ start` and `Z.start+k+len(t) ≥ start+len(h)`. Take the `p`-th ascending; if it doesn't exist, fail. Set `end = Z.start + k + len(t)`.
3. The evidence is `source[start:end]`, exact in Unicode codepoints with separators preserved.

Further rules:

- There is no case folding, Unicode normalization or whitespace collapsing.
- Anchors match within one line row, but a fragment may cross rows.
- A short fragment uses `h = t = text` with `p = 1`.
- Within one `x` list, fragments are strictly ascending by `start` and non-overlapping. Discontinuous evidence is just multiple fragments; the host renders gaps with an out-of-band marker that is never part of the text.
- Fragment length is unbounded, so the 600-char case is a single fragment.
- Identical fragments may be shared across nodes.

## 4. Parse, overflow and capacity rules (fail-closed, offline)

**Order of checks.** The first failure aborts with a code. No partial expansion, salvage, retry, chunking or narrowing is ever produced.

1. `finish_reason == "stop"`, checked before parsing.
2. Raw body is at most **600,000 UTF-8 bytes**. This is a judgment-call value.
3. Strict JSON: reject duplicate keys, trailing text, NaN/Infinity, non-integer numbers where integers are required, and an incomplete `END`-terminated object.
4. Closed keys and types. A stray `c` or `v: "r14.2"` is rejected.
5. Bounds and sentinels.
6. ID formats and the span enum.
7. Unit invariants.
8. Node and link invariants.
9. Fragment resolution.
10. Expansion.

**Kinds of limit.**

- **Codepoint limits** (after JSON unescape; a surrogate-pair escape counts as 1): `s` 280; unit, node, link and dimension `r` 180; `g` 120; anchors 1..48.
- **Byte limit:** the raw body only.
- **Count limits:** units < 160, nodes < 400, links < 400; leaf fragments 1..8; operator fragments 0..4; link fragments 0..2; dimension fragments 0..4; children 2..8; `d`/`b` 0..16; `e` 1..6; depth 12.

If faithful representation needs more than any limit, the attempt fails rather than shortening.

**Unknowns.** Output-token and reasoning-token usage through the subscription bridge are **not measured and not knowable offline**. No limit setting guarantees that a maximal valid object fits the model's output window. The limits detect overflow; they don't prevent it.

## 5. Expansion and completeness flags

The host emits:

- **Per node:** `{id, op, args, evidence:[{a, z, start, end, text}], model_gloss, q, r, unresolved_reference: op=="R"}`.
- **Per unit:** `applicability ∈ {"none_reported", "reported_nonexhaustive", "unknown"}` and the unit's links. The string "unconditional" is never emitted.
- **Envelope constants:** `completeness:"unverified"`, `condition_coverage:"unverified"`, `semantic_validity:"unverified"`, `evaluation:"not_performed"`, `production_eligible:false`, `action_ready:false`, and `evidence_match:"exact"` (only on success).

Exact evidence, a valid graph and `END` do not prove that coverage is exhaustive or that the semantics are correct. Uncovered-span counts may be reported only as diagnostics.

## 9. Tests

### Positive

1. Example graphs validate, and the expanded texts equal the expected substrings and offsets.
2. Repeated phrase with `o=1` and `o=2` resolves to distinct anchors.
3. A 600-char fragment within one row, and a cross-row variant (a≠z) containing CRLF, NEL and U+2029 separators, round-trip byte-exact.
4. A discontinuous leaf with two ascending fragments.
5. A shared node linked to two units, with a third unit at `p=0` and zero links.
6. An R leaf with `q2` under an `m1` unit is valid.
7. Each deadline state validates: stated, absent (with unit `q≠0`), ambiguous (with `r`), and `na` on the basis dimension.
8. **Accepted semantic defects:** OR swapped for AND; a wrong `acts` target; `if` used where `onlyif` was meant. All validate, which documents that semantics are unchecked.
9. `p=0` expands to `none_reported`, never "unconditional".

### Negative

Each of these must be rejected.

1. **Anchor resolution:** anchor absent; `o` greater than the occurrence count; no tail candidate; ordinal(z) < ordinal(a); fragments overlapping or descending.
2. **Unicode:** an NFD vs NFC anchor; a case-variant anchor.
3. **Graph:** a cycle (c1→c2→c1); a self-child; a dangling child or link; an orphan node; a duplicate node ID; a duplicate child.
4. **Arity:** NOT with 2 children; EXC with 1 or 3; AND with 1; L with children; R with `q≠2`; ALT with `q=0`; depth 13.
5. **Applicability links:** `p=1` with no applicability link; `p=0` with an `if` link; `p=2` with unit `q=0`; two `if` links on one unit; a duplicate `(u,w,n)` triple.
6. **Deadline slot:** `y` set on k≠3; `absent` with fragments; `ambiguous` with empty `r`; `na` on the clock dimension; an absent dimension with unit `q=0`.
7. **Legacy fields:** a `c` key present; `v: "r14.2"`.
8. **Modality:** `m5` with `q0`.
9. **Envelope:** `finish_reason: "length"`; truncated JSON; trailing text; duplicate keys; `z ≠ "END"`.

### Capacity

1. Units: 159 passes, 160 is rejected as `capacity_review`. The same holds for nodes and links at 399 vs 400.
2. String caps: exactly at the cap passes, cap+1 fails. An astral character counts as 1 codepoint, including when written as a JSON escaped surrogate pair.
3. 8 leaf fragments pass, 9 fail. A 48-codepoint anchor passes, 49 fails.
4. A raw body over 600,000 bytes is rejected before parsing.
5. An error in the final node rejects the whole output, and no partial expansion is emitted.

## 10. Migration rationale

- `c180` forced long qualifications into lossy paraphrase.
- It encoded scope and nesting in prose, which made leakage like the telephone case invisible.
- It conflated deadline dimensions, applicability and performance content.

R15 changes the following, under a new directory and version, and leaves the R14 schema, validator and prompt byte-frozen:

- `c` is removed.
- Unit fields are otherwise preserved: provenance `e`, hashes `h`/`t`, modality `m`, roles k5/k4, relationships k7, and `q`/`r`.
- The `splitlines` span table is reused unchanged as the coordinate system for anchors.

R14 outputs are **not** auto-converted, because prose can't be parsed into a graph deterministically. The public R14 source is used only as structural regression under R15. No live or unseen performance claim is made.

## 11. Non-goals

R15 does not do any of the following:

- Evaluate booleans or decide action eligibility.
- Resolve references.
- Determine sufficiency vs necessity.
- Determine OR exclusivity.
- Normalize deadlines or timezones.
- Check legal correctness.
- Produce a canonical unique graph (multiple valid graphs per source are allowed and are not canonicalized).
- Prove coverage.
- Chunk, retry or salvage.

## 12. Remaining judgment calls (flagged, not silently decided)

- **Limit values:** 400 nodes and links, 48-codepoint anchors, 600 KB body, depth 12, gloss 120.
- **`if` vs `onlyif`** assignment is left to the model, and the host doesn't check it.
- **`unless` link vs `EXC`:** the guidance is that a carve-out against the assertion uses `unless`, and a carve-out against a specific condition uses `EXC`.
- **ALT vs node `q1`** for scope ambiguity: both are valid representations.
- **Gloss:** allowing any gloss at all is a choice; setting `g=""` everywhere is a stricter option.
- **Connective fragments** on operators and links are optional, not required.
- **Role set:** whether `acts` and `qual` are both needed. They are kept because examples 1 and 3 require typed homes that are neither applicability nor content.
