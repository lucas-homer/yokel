## Outcome and primary decisions

Fable found no blocker to bounded offline implementation, but called out five design/documentation issues and argued typed operators currently add less preservation value than an opaque exact qualified clause with an explicit unit link. This is advisory judgment, not code review, live release approval, provider compatibility or measured capacity.

**Priority1 — applicability consistency:** confirmed textual mismatch: qual may appear with any p, including0, despite the host rule that unknown scope cannot silently become p0. For an uncertain applicability qualification, require p2 with unit uncertainty and qual-link uncertainty. Distinguish this from a clearly non-applicability qualification; either document that narrower role or conservatively mark p2. Fable suggests p0 forbids qual, and qual-only units use p2. Primary should settle this invariant before schema freeze; no frozen design edits made here.

**Priority2 — preservation baseline versus operator complexity:** Fable recommends mandatory full-clause root evidence or parent-covering evidence with child containment; typed trees optional if they add no proven diagnostic value. This supports evaluating an opaque qualification baseline objectively. Host caution: containment only proves membership in selected covering text, not scope/coverage correctness, and can reject valid cross-sentence/distributed conditions if applied indiscriminately. Current operators deliberately lack covering evidence. Mandatory containment is a material design change requiring synthetic distributed/shared-clause cases, not a one-line correctness fix. Compare complete output size and scope diagnostics; no compression advantage is established.

**Anchor convention:** same-row equal-head/tail with headOcc2/tailOcc2 deterministically resolves from the second to third occurrence, not the second alone. Codex reproduced this in host-assessment.json. Require tailOcc1 for a designated short fragment or explicitly distinguish/document longer equal-anchor ranges. Fable's blanket rejection removes valid deliberate wider ranges; it is a proposed constrained convention, not proof that the current algorithm is nondeterministic. Short exact fragments can still omit essential clause text while validating. End occurrence is filtered relative to the chosen head, never an unconditional row occurrence; comparisons must preserve that definition.

**Taxonomy/documentation:** define L with unresolved embedded term versus R whose governing condition content is unavailable, or accept equivalent unresolved-reference annotations in semantic review. The host cannot deterministically classify source meaning. Explicitly scope legacy c rejection to Unit; deadline y.c is valid by its closed type. Host OR exclusivity override already takes precedence over original advisory text; downstream prompt/spec should present one rule. Specify reused row geometry concretely as exact splitlines(keepends=True) [span_id,start,end,text] rows, contiguous source coverage, Unicode scalar/codepoint offsets and preserved terminators; tail/head overlap is allowed by current algorithm and must be documented or intentionally revised.

**Implicit logic and scope:** Fable objects to tenant+lease AND without connective evidence and suggests a single opaque leaf. Natural-language “tenants with a lease” may support conjunction without literal AND; requiring q1 for every implicit operator would be a new policy, not a universal semantic correction. Conservative opaque clause is appropriate when scope is uncertain. Waiver target must still identify the lease-duration restriction rather than unintentionally the entire tenant class. Do not impose Boolean evaluation. Shared condition nodes require explicit per-unit links; d/b/context/evidence does not propagate applicability.
