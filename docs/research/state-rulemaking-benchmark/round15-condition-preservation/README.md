# R15 condition preservation: implementation and offline evaluation

The useful change is to preserve complete source clauses through exact host-resolved anchor pairs, instead of asking a model to repeat qualifications inside a 180-character prose field. The new experimental contract records which observation each clause qualifies, preserves explicit uncertainty, and keeps deadline dimensions separate. The host recovers the selected source text without clipping or normalization. It does not prove that the model selected every necessary clause or interpreted its scope correctly.

The primary recommendation is **complete opaque clauses first, typed logical structure where its diagnostic value warrants the extra interpretation and serialization**. Both representations are supported by this prototype. Authored comparisons show that anchored long clauses can be smaller than repeated full prose, but typed graphs can be considerably larger than opaque clauses. These are representation measurements, not generated extraction quality or semantic-equivalence results.

Fable (`claude-fable-5-1`) designed adversarial controls before design exposure, reviewed the design, and assessed the original implementation and test evidence. Claude used the isolated **Claude.ai Max subscription bridge**; no OpenRouter Claude or Anthropic API route was used. Claude did not edit files or execute tests.

The original r15.0 protocol is frozen. Opus review identified a graph-traversal robustness gap under a lowered Python recursion limit, two negative tests whose intended guards were masked by earlier failures, and mutable list aliases in the inverse. The new **r15.1** revision uses iterative graph traversal, tests the intended guards directly, and returns independent list copies. The deep invalid graph rejects with a controlled error at recursion limits 1000 and 600; the original default runtime had already rejected it correctly. All **31 protocol tests, 17 unchanged independent methods, and six targeted hardening checks pass**, reproduced by the primary. Fable found no material defect in the bounded revision diff. Its original no-blocker assessment preceded the later recursion reproduction and remains explicitly limited; the final diff review and revised independent tests address those changes. No comprehensive correctness or live approval follows.

The independent 17-method suite passes against both frozen versions and demonstrates the boundary explicitly: a shortened exact leaf, missing applicability link, wrong governed unit, or swapped operator can remain structurally valid. An unresolved qualification now requires an unknown applicability state and explicit link/unit uncertainty. Context links never inherit conditions or establish universal applicability. Every expanded record remains semantically unverified, with production eligibility and action readiness false. Full waiver matrices, current/proposed scope interpretation, and generic paraphrase entailment remain deferred rather than counted as covered.

Exact inverse checks establish consistency with the supplied compact metadata, not authenticity relative to an unavailable original response. A future runtime must pin the original raw response and its digest independently. Source fragments preserve codepoint ranges; they do not guarantee whole graphemes, complete clauses, legal interpretation, or exhaustive source coverage.

**Live routing is not ready.** The current offline schema uses positional tuples, nullable unions, node-ID patterns, and schema metadata that the existing runtime checker does not support. It rejects every candidate schema measured here. Provider acceptance is unverified. A reviewed compatible fragment wire format and schema, or a new strictly validated runtime dialect, must precede dispatch; bypassing the checker is not a solution. The schema's repeated source-ID enums also materially increase input size.

The next comparison should retain exact full-clause preservation as its baseline, measure any optional typed-graph layer against that baseline, and use new source-only inputs with independently reviewed scope/exception expectations. Before a paid run, resolve wire/schema compatibility, freeze the complete request and intact stop rules, and obtain sufficient budget authorization. This round made no paid extraction call and changed no credentials, native runner, production service, or shared contracts. State work remains research.
