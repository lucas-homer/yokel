Preserve exact raw spans while matching close cues across whitespace. Use notice structure, rather than any line-start phrase, to count notices. Verify these changes against the concrete KY, OH, NM, and MI failures before a newly frozen run on fresh sources.

Keep request-size handling explicit and preserve full-source verification; five size-blocked rows provide no Jev evidence. Define valid alternative emails as a set separately from mutually inconsistent same-phase deadlines, and retain source identity uncertainty independently of model conflict judgments. These are follow-up design recommendations only; no frozen code or outcomes were changed.
